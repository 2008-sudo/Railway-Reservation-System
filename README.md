# Railway-Reservation-System
Java-based Railway Reservation System group project
## Features
1. View Train Details
2. Check AC, Sleeper and General Seats
3. Book Tickets
4. Cancel Tickets
5. View Booking History
6. Waiting List

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- Exception Handling
